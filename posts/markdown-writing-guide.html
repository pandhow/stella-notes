代码块与高亮

Python：

def hello(star: str) -> str:
    return f"Hello, {star}!"

print(hello("星海"))

JavaScript：

const stars = ["参宿四", "织女", "北极星"];
stars.forEach(s => console.log(`晚安，${s}`));

python build.py && echo "站点生成完成"

写作习惯建议

  1. 先写大纲，再填血肉
  2. 一屏之内必有小标题，方便扫读
  3. 表格只在真正有二维信息时使用
  4. 代码块注明语言，高亮才有意义
