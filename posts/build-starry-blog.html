从零搭建一座星空博客：我的静态站点实践

发布于 2026-08-15 · 约 1 分钟（270 字） · 建站 前端

为什么选静态站点

博客的第一性原理是内容被阅读。动态框架很酷，但对一个以文字为主的站点来说，静态 HTML 才是正解：

  • 打开即所得，没有白屏等待
  • 托管成本几乎为零，Cloudflare Pages / GitHub Pages 随便选
  • 搜索引擎爬虫看到的就是完整内容，SEO 天然友好

不要温和地走进那个良夜。——狄兰·托马斯

技术栈一览

层 选型 理由
生成器 Python + Markdown 自己掌控每一寸 HTML
高亮 Pygments 服务端渲染，零 JS 开销
部署 静态托管 + CDN 全球秒开
搜索 纯前端索引 小数据量足够快

构建脚本长什么样

核心逻辑不到两百行，伪代码如下：

import markdown

md = markdown.Markdown(extensions=["extra", "codehilite", "toc"])
html = md.convert(post_text)
toc = md.toc  # 自动生成文章目录

性能的底线指标

我给自己定了三条红线：

  1. Lighthouse 性能评分 ≥ 90
  2. 移动端首屏 ≤ 2 秒
  3. 所有图片懒加载 + WebP/SVG
